# TCP Chat Application

This repository contains a simple TCP chat application developed for CST311. It brings together several networking assignments that used Mininet, a simulated network running inside an Ubuntu virtual machine. The network is defined programmatically with Python and includes virtual switches and routers.

The project demonstrates end-to-end connectivity and stateful session handling through TCP sockets. It includes a chat server and two clients, all implemented in Python.

## Repository contents

| File | Description |
| --- | --- |
| `pa4_chat_client.py` | TCP chat client implementation |
| `pa4_chat_server.py` | TCP chat server implementation |
| `legacy_network.py` | Mininet network definition, including virtual network devices and links |
| `pa4_network_diagram.pdf` | Diagram of the configured network |

## Mininet

Mininet is a lightweight network emulator for creating realistic virtual networks of hosts, switches, and routers. Learn more at the [official Mininet website](https://mininet.org/).
